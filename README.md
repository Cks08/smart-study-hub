# Smart Study Hub 📚

A personalized study management platform designed to help students organize their academic resources, manage deadlines, and study more efficiently in one place.

## ✨ Features

- 📝 **Notes Management** — Organize and access study notes.
- 📄 **PYQ Repository** — Keep previous year question papers accessible.
- ⏰ **Deadline Tracker** — Track academic deadlines and important tasks.
- 🎯 **Study Organization** — Manage study resources in one centralized platform.

## 🎯 Objective

To simplify academic planning by bringing study materials, question papers, and deadline management together in a single platform.
